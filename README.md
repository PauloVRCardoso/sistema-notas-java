# Sistema de Notas — Java

## Sobre o projeto

Sistema de gerenciamento de notas desenvolvido em Java como parte dos meus estudos de Engenharia de Software e Programação Orientada a Objetos.

O projeto começou com as aplicações do que foi ensinado na aula 01 da apostila da faculdade, com o objetivo de aplicar fundamentos da linguagem Java por meio do desenvolvimento de uma aplicação de console.

A proposta é continuar evoluindo o mesmo sistema ao longo das Aulas 02 a 06, incorporando novos conhecimentos e aprimorando sua estrutura.

## Funcionalidades implementadas

- Cadastro de alunos e suas notas.
- Validação de notas entre 0 e 10.
- Cálculo da média de cada aluno.
- Classificação de alunos como aprovados ou reprovados.
- Listagem dos alunos cadastrados.
- Consulta de alunos pelo nome.
- Estatísticas da turma.
- Listagem em ordem inversa de cadastro.
- Menu interativo no console.

## Conceitos de Java praticados

**Fundamentos da linguagem**

- Pacotes, classes e método `main`.
- Tipos de dados: `String`, `int`, `double` e `boolean`.
- Variáveis e operadores matemáticos.
- Entrada de dados com `Scanner`.
- Saída formatada com `printf`.

**Estruturas de controle**

- Condicionais `if`, `else` e `switch`.
- Operador ternário.
- Operadores lógicos `&&`, `||` e `!`.
- Estruturas de repetição `while` e `for`.
- Comandos `break`, `++` e `+=`.

**Coleções**

- Arrays e `ArrayList`.
- Métodos `add()`, `get()`, `size()` e `contains()`.
- Comparação de textos com `equals()`.
- Inversão de listas com `Collections.reverse()`.

## Tecnologias utilizadas

- Java
- Eclipse IDE
- Git e GitHub

## Como executar

1. Clone o repositório.
2. Abra o Eclipse.
3. Importe o projeto como projeto Java existente.
4. Execute a classe `Principal`, localizada no pacote `escola`.
5. Utilize o menu apresentado no console.

## Próximas etapas

O projeto continuará sendo desenvolvido durante as Aulas Práticas 02, 03, 04, 05 e 06 de Programação Orientada a Objetos.

As próximas funcionalidades e alterações de arquitetura serão definidas de acordo com os conteúdos estudados em cada aula.

Consolidar os fundamentos de Java e acompanhar, na prática, a evolução de um programa simples para um sistema com uma estrutura mais organizada, aplicando progressivamente conceitos de Engenharia de Software e Programação Orientada a Objetos.
